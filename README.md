# 預算記帳 PWA

## 功能
- 本月預算總覽
- 23 個分類的預算 / 已支出 / 剩餘 / 百分比
- 新增、編輯、刪除交易
- 月份切換
- 自訂分類預算
- 匯入現有 BudgetTrackingData JSON
- 匯出 JSON / CSV
- LocalStorage 本機保存
- PWA / 可加入 iPhone 主畫面

## 本機預覽
直接打開 `index.html` 可以使用大部分功能；PWA 安裝與 Service Worker 需要透過 HTTPS 或 localhost。

## 部署
把整個資料夾上傳到 Netlify、Vercel、GitHub Pages 或任何 HTTPS 靜態網站主機即可。
在 iPhone Safari 打開部署後的網址 → 分享 → 加入主畫面。
